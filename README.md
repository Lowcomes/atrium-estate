# Атриум

Интерактивный прототип для презентации управления коммерческой недвижимостью. Интерфейс на русском языке, 52 вымышленных объекта в Москве и пять рабочих ролей.

**Публичная версия** — [открыть приложение](https://lowcomes.github.io/atrium-estate/).

## Проведение презентации

Начните с обзора портфеля. Нажатия на показатели, столбцы графика и строки реестров открывают соответствующие записи. В нижней части боковой панели доступен «Режим презентации». Кнопка профиля меняет роль.

1. **Закупка.** Откройте «Фильтры для вентиляции» в согласованиях. Подпишите заявку от лица директора. Перейдите в профиль снабжения, откройте закупку, задайте поставщика и цену и подтвердите доставку. К поставке можно приложить накладную. Редактирование заявки создаёт новую версию, для которой нужно новое решение директора.
2. **Выполнение работ.** В профиле технического специалиста откройте задачу «Проверить приточную вентиляцию». Передайте отчёт на проверку. Управляющий может принять работу или вернуть её с причиной. Директор видит историю и закрывает принятую задачу.
3. **Аренда.** В финансах выберите «Задолженность». Откройте начисление и зарегистрируйте оплату под уникальным номером платёжного документа. Остаток, отчёт и поступления пересчитаются.
4. **Ремонт.** Добавьте запись обслуживания из карточки помещения, выберите связанную задачу и заполните расходы. Завершённый ремонт появляется в истории здания, помещения и задачи. Стоимость работ, материалов и дополнительные расходы образуют одну расходную операцию. Ущерб и потерянный доход учитываются в отчёте об убытках.
5. **Строительство.** Откройте строящийся объект, создайте задачу или заявку в его карточке. После ввода в эксплуатацию здание сохраняет идентификатор и все связи.

Из режима презентации можно восстановить исходные вымышленные данные. Сброс требует повторного нажатия.

## Запуск и проверка

Для локальной разработки установите Node.js 22 и выполните следующие команды.

```sh
npm ci
npm run dev
```

Для публикации выполните `npm run build`. Каталог `docs/` содержит статический сайт для GitHub Pages. Маршруты используют фрагмент URL, так что ссылки на карточки и разделы открываются напрямую.

Для сквозной проверки запустите локальный сайт на порту 4192 и выполните `npm test` в другом терминале. Переменная `ATRIUM_URL` задаёт другой адрес, а `CHROME_PATH` — путь к Chromium или Google Chrome. Тест создаёт изолированный браузерный профиль и проверяет разделы, роли, согласования, файлы, расчёты и мобильную навигацию.

## Данные и границы прототипа

- React, Radix UI Dialog, Lucide, Leaflet и Vite. Основной интерфейс, фотографии и шрифты входят в сборку.
- Записи сохраняются в localStorage, загруженные файлы — в IndexedDB этого браузера. Посетители ссылки получают собственные копии исходного портфеля. Смена роли используется для демонстрации представлений интерфейса.
- Все операции выполняются на устройстве посетителя. Общая база сотрудников, серверная авторизация, неизменяемый серверный аудит, квалифицированная электронная подпись и резервное копирование на сервер относятся к следующему этапу.
- Решение директора связано с версией заявки и содержит имя, время и идентификатор демонстрационной подписи. Действуют внутренние уведомления. Подключения к банкам, электронной почте, Telegram, MAX и push-сервисам в эту версию не входят.
- Карта использует онлайн-подложку OpenStreetMap. Авторство картографических данных — [OpenStreetMap contributors](https://www.openstreetmap.org/copyright). Иллюстративные архитектурные фотографии — Unsplash, шрифт Inter распространяется по SIL Open Font License.
